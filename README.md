# 🏆 FitHero TMA — Workout RPG & FUT Athlete Card Generator

**FitHero** — это полноценное **Telegram Mini App (TMA)** для геймификации тренировок и здорового образа жизни. Превращайте физические упражнения и саморазвитие в прокачку характеристик персонажа (RPG), собирайте динамические **FUT-карточки атлета**, ведите стрик дисциплины и соревнуйтесь в таблице лидеров.

---

## ⚡️ Основные возможности

1. **4 ключевые дисциплины развития:**
   - 💪 **Сила (СИЛ)**: Отжимания с автоматическим компьютерным зрением (нейросеть считает повторения через камеру телефона в реальном времени).
   - ⚡️ **Выносливость (ВЫН)**: Бег и кардио с верификацией скриншотов трекеров (Strava, Nike Run Club, Garmin, Apple Fitness) через Gemini AI.
   - 🌪 **Ловкость (ЛОВ)**: Комплексы стретчинга и растяжки с датчиком стабилизации позы и таймерами удержания.
   - 🧠 **Интеллект (ИНТ)**: Чтение книг и саморазвитие с фотофиксацией страницы и интеллектуальным анализом ключевых мыслей нейросетью.

2. **Динамические FUT-карточки атлета (FIFA Style):**
   - 6 визуальных рангов карточек, зависящих от уровня игрока:
     - 🥉 **Бронза** (Ур. 1–4)
     - 🥈 **Серебро** (Ур. 5–8)
     - 🥇 **Золото** (Ур. 9–12)
     - 💎 **Алмаз** (Ур. 13–17)
     - 🔴 **Легенда FitHero** (Ур. 18–24)
     - 🌌 **Мифик 99 OVR** (Ур. 25+)
   - Генерация и скачивание карточки в высоком разрешении (`.PNG`) через Canvas.
   - Шаринг карточки в Telegram с актуальными характеристиками.

3. **Стрик дисциплины и календарь:**
   - Интерактивный календарь тренировок с метриками регулярности, сессиями и сожженными калориями.

4. **Лента сообщества и Зал Славы:**
   - Публикация отчетов о тренировках с фото и карточками.
   - Лайки, фильтрация по дисциплинам и просмотр профилей других атлетов.
   - Таблица лидеров по общему рейтингу (ОБЩ) и отдельным характеристикам.

## 🛠 Стек технологий

- **Фронтенд:** React 19, TypeScript, Vite, Tailwind CSS v4, Motion, Canvas-Confetti, Lucide Icons.
- **Бэкенд:** Express, Node.js, `@google/genai` (Gemini 2.5/3.7 Flash).
- **Платформа:** Telegram WebApp SDK (`@telegram-apps`).

## 🚀 Быстрый старт локально

### 1. Требования
- **Node.js** версии 18+ или 20+
- **npm** или **pnpm** / **yarn**

### 2. Установка зависимостей
```bash
git clone https://github.com/YOUR_USERNAME/fithero-tma.git
cd fithero-tma
npm install
```

### 3. Настройка переменных окружения
Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```

Укажите ваш ключ Gemini API (по желанию для нейросетевой верификации скриншотов):
```env
GEMINI_API_KEY="AIzaSy..."
PORT=3000
```
> *Примечание: Если ключ не указан, приложение использует встроенные резервные алгоритмы анализа.*

### 4. Запуск в режиме разработки
```bash
npm run dev
```
Сервер запустится на `http://localhost:3000`.

## 🌐 Бесплатный хостинг на GitHub Pages (Рекомендуется!)

Проект уже содержит готовый автоматический сценарий **GitHub Actions** (`.github/workflows/deploy.yml`). При отправке кода в репозиторий GitHub автоматически соберет и опубликует ваше приложение на быстрый бесплатный HTTPS-хостинг **GitHub Pages**!

### Как включить GitHub Pages в 2 клика:
1. Зайдите в ваш репозиторий на **GitHub.com**.
2. Перейдите во вкладку **Settings** (Настройки) → слева выберите раздел **Pages**.
3. В пункте **Build and deployment** → **Source** выберите:
   👉 **`GitHub Actions`** (не Deploy from branch).
4. Запустится автоматический экшен во вкладке **Actions**, и через 1 минуту вы получите постоянный публичный HTTPS-адрес:
   `https://ВАШ_ЛОГИН.github.io/fithero-tma/`
5. Этот адрес идеально подходит для вставки в Telegram Mini App в [@BotFather](https://t.me/BotFather)!

## 🌐 Альтернативные варианты деплоя (с Node.js сервером)

Если вам требуется собственный Node.js бэкенд с прямым проксированием запросов:

### Вариант А. Render.com
1. Создайте **Web Service** на [Render.com](https://render.com).
2. Подключите ваш GitHub-репозиторий.
3. Укажите параметры:
   - **Environment:** `Node`
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm run start`
4. В разделе **Environment Variables** добавьте `GEMINI_API_KEY` (если используете).
5. Получите готовый URL вида `https://fithero-tma.onrender.com`.

### Вариант Б. Railway.app / VPS / Vercel
- **Railway**: Подключите репозиторий, Railway автоматически развернет `package.json`.
- **VPS**: `npm run build && pm2 start dist/server.cjs --name "fithero"`.

## 🤖 Настройка Telegram Бота и Mini App

Для запуска приложения внутри Telegram выполните простую настройку через официального бота **[@BotFather](https://t.me/BotFather)**:

### Шаг 1. Создание бота
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram и отправьте команду:
   ```text
   /newbot
   ```
2. Введите имя бота (например, `FitHero Workout RPG`).
3. Введите username бота (например, `FitHeroAppBot`).
4. Сохраните полученный **API Token**.

### Шаг 2. Создание Mini App
1. В диалоге с [@BotFather](https://t.me/BotFather) отправьте команду:
   ```text
   /newapp
   ```
2. Выберите созданного бота.
3. Введите название приложения (например, `FitHero App`).
4. Введите краткое описание.
5. Загрузите иконку приложения (квадратное изображение 640x640 px).
6. В ответ на запрос **Web App URL** укажите ваш HTTPS-адрес (например, `https://fithero-tma.onrender.com` или адрес вашего хостинга).
7. Задайте короткое имя (short name), например `app`.

### Шаг 3. Настройка кнопки меню (Menu Button)
Чтобы в чате с ботом в левом нижнем углу появилась постоянная кнопка запуска:
1. Отправьте [@BotFather](https://t.me/BotFather) команду:
   ```text
   /setmenubutton
   ```
2. Выберите вашего бота.
3. Введите URL вашего приложения (`https://...`).
4. Введите текст кнопки, например `⚡️ Открыть FitHero`.

### Шаг 4. Прямая ссылка на запуск
Теперь пользователи могут запускать приложение по прямой ссылке:
`https://t.me/YOUR_BOT_USERNAME/app` или `https://t.me/YOUR_BOT_USERNAME?startapp=ref`
